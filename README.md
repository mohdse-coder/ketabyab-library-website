# کتاب‌یاب | Ketabyab
### وب‌سایت کتابخانه — پروژه دانشگاهی

**کتاب‌یاب** یک پروژه وب دانشگاهی برای نمایش و مرور محتوای مرتبط با کتابخانه است که با هدف تمرین طراحی رابط کاربری و توسعه وب ساخته شده است.

### فناوری‌ها
- HTML5 و CSS3
- Bootstrap
- PHP و Laravel

### درباره پروژه
تمرکز اصلی من در این پروژه بر ساختار صفحات و طراحی رابط کاربری با HTML و CSS بوده است. برای پیاده‌سازی بخش‌هایی از بک‌اند PHP و Laravel از ابزارهای هوش مصنوعی کمک گرفته‌ام و همچنان در حال یادگیری این فناوری‌ها هستم.

### تصاویر پروژه
در ادامه، تصاویری از رابط کاربری پروژه را مشاهده می‌کنید.

### وضعیت پروژه
پروژه در حال توسعه است و برخی قابلیت‌ها ممکن است هنوز کامل نشده باشند.

# Ketabyab | Library Website
### University Web Development Project

Ketabyab is a university web project focused on presenting library-related content and practicing web design and development.

### Technologies
- HTML5 and CSS3
- Bootstrap
- PHP and Laravel

### About the Project
My primary focus has been building page layouts and styling the user interface with HTML and CSS. AI tools assisted with parts of the PHP and Laravel backend, which I am still learning.

### Project Status
The project is a work in progress, and some features may be incomplete.
